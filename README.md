
# Kitchen Companion  

## Overview  
**Kitchen Companion** is a responsive website built with **HTML**, **CSS**, and **JavaScript**, offering a collection of recipes for every meal of the day. From breakfast to dessert, this platform ensures easy access to delicious recipes with filters for dietary needs like gluten-free, dairy-free, and healthy options.  

---

## Features  
- **Recipe Categories**:  
  - Breakfast  
  - Lunch  
  - Dinner  
  - Dessert  

- **Dietary Filters**:  
  - Gluten-Free  
  - Dairy-Free  
  - Healthy Options  

- **Detailed Recipe Pages**:  
  - List of ingredients  
  - Step-by-step cooking instructions  
  - High-quality images  

---

## How to Use  
1. Clone the repository:  
   ```bash
   git clone https://github.com/your-username/kitchen-companion.git
   ```
2. Open the project folder and launch `index.html` in your browser.  
3. Browse meal categories and apply dietary filters to find a recipe.  
4. Select a recipe to view details and start cooking!
